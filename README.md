## Deskripsi Singkat Mengenai Repository

Repository ini merupakan ruang kerja digital yang digunakan untuk menyimpan, mengelola, serta mendokumentasikan seluruh rangkaian tugas, latihan praktik, dan proyek aplikasi web interaktif yang dikembangkan selama mengikuti kegiatan workshop "Building with AI, Managing Change with GitHub".

## Tujuan atau Kegunaan Repository

* **Pengendalian Versi (Version Control):** Menerapkan sistem kontrol versi menggunakan Git untuk melacak setiap perubahan kode dari waktu ke waktu.

* **Kolaborasi dan Penyimpanan Online:** Menyimpan kode sumber proyek secara aman di GitHub agar mudah diakses serta dikelola secara terstruktur.

* **Dokumentasi Pembelajaran:** Menjadi portofolio dan catatan transparan mengenai progres belajar pemanfaatan AI (*Prompt Engineering*) serta manajemen repositori Git/GitHub.


## Informasi Mengenai Kegiatan Workshop

Kegiatan workshop yang didokumentasikan bertajuk **"Building with AI, Managing Change with GitHub"** yang dibawakan oleh **Nugi Farhan** (Senior Product Designer). Workshop ini berfokus pada dua pilar utama di industri teknologi modern:

1. **Prompt Engineering:** Cara merancang instruksi yang spesifik dan terstruktur dengan menerapkan komponen *Role, Task, Context, dan Format* agar model AI dapat memberikan hasil yang optimal, akurat, dan relevan.

2. **Version Control & GitHub:** Penggunaan Git dan platform GitHub untuk mengelola manajemen perubahan pada kode, memahami alur kerja (*Git Workflow* mulai dari *Working Directory*, *Staging Area*, hingga *Repository*), serta melakukan perintah esensial seperti `init`, `add`, `commit`, `push`, dan konfigurasi SSH Key.
